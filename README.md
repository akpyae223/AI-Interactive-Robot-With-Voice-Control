# AI-Interactive-Robot-With-Voice-Control


## Project Overview

This project focuses on designing and developing a four-wheel mobile robot with an AI-powered voice assistant. The robot uses voice commands to control its movement and provides voice feedback to improve human-robot interaction.A 4-wheel differential-drive AI mobile robot powered by a Raspberry Pi 5, ESP32, and Arduino Uno featuring offline Vosk voice recognition, wake-word activation, multi-directional ultrasonic obstacle avoidance, and an interactive 5-inch DSI display.

## Technologies Used

- Raspberry Pi 5
- Arduino Uno R3
- ESP32
- Python(Vosk AI)
- DC Motors
- Motor Driver
- Gyro Sensor
- Ultrasonic Sensors
- Microphone
- Speaker
- Voice Recognition

## Main Features

- Voice-controlled robot movement
- Forward and backward movement
- Left and right turning 90 degrees
- Stop command for safety
- Obstacle detection with Ultrasonic Sensor
- Face Detection with Pi Camera
- Answering General Questions and Voice feedback system
- Integration of hardware and software components

## System Architecture

Raspberry Pi acts as the main processing unit, handling voice recognition and command processing. ESP32, Arduino and the motor drivers, ultrasonic sensors, gyro sensor control the four DC motors to perform the robot's movements and generate smooth turn and safety.
